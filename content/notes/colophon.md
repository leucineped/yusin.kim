This site is static HTML generated by a single Python script. There is no
database and no server-side code. One third-party script runs: a
[GoatCounter](https://www.goatcounter.com) beacon that counts pageviews without
cookies and without storing anything that identifies a reader. Nothing else on
any page is JavaScript.

The generator reads Markdown files from `content/`, applies two HTML templates,
and writes `docs/`. It produces an RSS feed, a sitemap, and a `robots.txt`.
Dependencies: the Python standard library and [mistune](https://github.com/lepture/mistune)
for Markdown.

There are three kinds of pages. **Writing** is longer and usually reports
something I measured. **Notes** are shorter and rougher. **Etc.** is everything
that is not work. Some pages carry an epistemic label — seedling, budding,
evergreen — indicating how much I would bet on them.

Every page shows its date and word count.
